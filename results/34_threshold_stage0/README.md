## 핵심 결과

**① 구판 오염도 = 0.** 마스킹 질량이 전 플랫폼 0~0.2% → E9 보고치(ε_min 중앙값 3.2~3.8칩)는
흡수 순수치였음 확정. 설계가 우려한 정정 사항은 실제로 발생하지 않음.

**② P1 무차원 자기일관성 — 부분 성립.** ε(칩) 3.5배 퍼짐(1.2~4.2) → α_min 2.1배(0.100~0.210)로
수축(무차원화 작동 방향). 단 A8(0.166~0.210) vs A12(0.100~0.132) 구조 잔존 — 행동 메뉴(경쟁자
지분 ρ)가 임계식에 들어가야 함을 시사. CFR 두 칸은 α 0.132 정확 일치.

**③ off 0-지배 지문의 이분법**: 학습 상대에게 전면 패배하는 플랫폼(CFR 칸 94~95%,
Random-학습 legacy 94.5%)에서 극대, TAG 학습에선 6% — ZCA 발현 강도와 대패의 동행.

**④ fixed 근거 내생성**: 5/6 플랫폼에서 chec 근거와 정합(α 0.105~0.160). 전이구간 플랫폼
(k20-A12, fixed5 2/5)에서만 복원 파탄(α=1.002) — 반실패 학습 Q로는 참값 복원 불가의 실증.

**⑤ M1 용량 probit (legacy8 α축 17점)**: α50=**0.120**, w=0.56 — 전이 중점 실측(8~15%)과 정합.
med(α_min)=0.210과의 차이 = **성공은 커버리지 절반이 아니라 소수(θ≈0.30)에서 발생** — 검정력
보정층(Φ)이 필요하다는 정량 근거 (설계 B안 예측 방향).

**⑥ M2 커버리지-probit 이식(θ=0.30, w_F=0.28)**: out-of-sample **10점 중 9점 적중**
(legacy8 K축 4용량 × 2계열 + 타 플랫폼 fixed5·chec_a30). **유일 실패 = k20-A12 fixed5**
(F=0.74 → P̂ 4.7/5 vs 관측 2/5) — 같은 F=0.74가 legacy8에선 5/5, k20-A12에선 2/5:
방문가중 커버리지가 셀 중요도(수익 기여)를 무시한다는 반증점. **게이트 A가 이 긴장의 결정 시험.**

**게이트 A 완승**: K-사다리 단조(fixed5 2/5 → 8·10·20 전부 5/5, 평균 +766→+884→+1979) —

**게이트 B 기각**: α축 이식 실패 — A12의 α 전이는 (0.15, 0.30] 구간(α=0.30은 5/5)으로,
복원된 α_min 분포(중앙값 0.100)가 **좌편향(과낙관)**이었음. K축 F(5)=0.74 과대예측(관측 2/5)과
합치면 단일 진단이 선다: **복원 분포의 좌측 꼬리 과대** — |Q|가 작은 셀의 잡음이 작은 임계값
질량을 부풀림(추정). 수정 경로(다음 반복): 셀 활동도(|Q|·방문수) 가중 + 좌측 꼬리 절사 후 재적합.

종합: 사전 등록 설계가 의도대로 작동 — 한 축은 검증, 한 축은 구체적 수리 방향과 함께 기각.
"정적 임계 조건은 K축(칩 단위 용량)에서 이식 가능, α축은 복원 편향 보정 필요"가 현재 상태.
(이후 3중 소거로 α축 성능 문턱의 원인 = FOLD 영-고정 확정 — 실험일지 보강 22~26.)

## 게이트 C 사전 등록 (상한 탐색 — 2026-08-04, 런 전 고정)

플랫폼 legacy8-A8(2M eps, 33번 규약 동일), chec α∈{1.0, 2.0} × s1–5 = 10런. 기준 = 기존
안정 구간: α 0.30~0.50에서 5/5 양수·평균 +988~+1546 (용량을 올려도 성능이 안 변하던 구간).

**예측 (방향만 — 정량 유도 불가를 정직 명시)**: 과대 가상비용이 "체크가 진짜 정답인 상황"의
가치까지 눌러 체크 기피를 만드는 경로(마스킹)로, ① α=1.0 평균이 안정 구간 하단(+988) 아래로
하락 ② α=2.0은 α=1.0보다 더 하락(용량 커질수록 부작용 커지는 단조 관계). 정량 예측을 못 박는
이유: 마스킹 셀 질량이 α=0.20 학습 Q에서 0.1%뿐이라 외삽 근거 부족 — 방향 예측만 등록한다.

**기각 기준**: 두 용량 모두 5/5 유지 ∧ 평균 ≥ +988 이면 상한 채널 기각 → α* "최적점" 주장을
접고 "임계 초과 후 [0.15, 2.0] 구간 안정(용량 튜닝에 둔감)"으로 마감.

**사후 지문 검사 예고**: 완료 후 ① analyze_threshold 마스킹 질량 변화 ② 행동 프로브(체크
비율 — 하락했다면 체크 기피가 실제 행동으로 나타났는지)로 기전 확인.

a50 0.3% → a100 2.8% → a200 2.1%로 예측 기전(용량↑ → 체크 기피↑)의 신호 **없음**.

**최종 판정 (보수)**: 팟의 200% 가상비용까지도 전 시드 흑자 유지 — 상한은 "급락 벽"이 아니라,
있더라도 완만한 경사이며 현 표본으로는 통계적으로 미확정. **α\* "최적점" 주장은 접는다.**
확정 가능한 정리: **하한은 급격(좁은 구간에서 0/5→5/5 반전) + 임계 초과 후 최소 [0.15, 2.0]의
넓은 안정 구간(용량 튜닝에 둔감)** — 처방의 실용 강점(과용량에 관대)으로 재프레임.
