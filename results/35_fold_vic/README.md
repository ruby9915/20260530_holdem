## 0.5단계 — FOLD 임계 지도 (학습 0회, `fold_threshold_map.csv`, 2026-08-06)

k20-A12 chec_a30 ×5시드의 벳 직면 셀(훈련 n(FOLD)≥30) 분석:
- **흡수 질량 70.0%** (비-FOLD 최선 대안이 전부 음수 — FOLD의 0이 argmax 지배)
- **α_f_min 방문가중 중앙값 = 1.016 (팟의 ~100%)** — CHECK(0.10~0.21)의 5~10배.
  기전: 폴드의 참값 |μ̂_F|가 작은(접어봤자 조금 잃는) 맥락이 많아 0을 끌어내리기 어려움.
- 커버리지: F(0.05)=0.01 · F(0.15)=0.03 · F(0.30)=0.07 · F(1.0)=0.50
- 27.5%는 해소 불능 추정(k_f≥1 — 대안이 폴드 추정 손실보다 나쁨 = 폴드가 진짜 정답인 셀)

**격자 수정(지도 기반)**: 설계 초안의 {0.05, 0.15, 0.30} → **{0.3, 1.0, 2.0}** — 저용량 앵커(7%
커버) / 예측 전이 중점(50%) / 고용량(과콜 위험 탐침)의 판별 배치.

**근사 3건 (정직 명시)**: ① μ̂_F = −c̄(r)/2 (기투자 절반 근사) ② s_f(α)=α/(0.5+α) 정적 근사
③ 커버리지→성적 링크는 vsRand 보정치의 vsMAN 이식(미검증 가정). CHECK판 게이트 B의 교훈
(정적 α 지도 ~5배 낙관)이 여기서도 재현될 수 있음 — **방향 예측 위주로 등록**한다.

## 1단계 사전 등록 (런 전 고정, 2026-08-06)

런: k20-A12 × TAG, chec_a30 + foldtime α_f ∈ {0.3, 1.0, 2.0} × s1–5 = 15런 (7.5M eps).
대조 = 기존 chec_a30 ×5 (α_f=0). 평가 = 상대 6종 × 100k×5.

| 예측 | 내용 |
|---|---|
| P1 (용량 순서) | vsMAN 개선 폭: α_f=0.3 미미(커버 7%) < 1.0 < 2.0 — 단조 |
| P2 (주 판정) | α_f ∈ {1.0, 2.0} 중 하나 이상에서 **vsMAN 양수 시드 ≥3/5** (현행 chec_a30: 2/5, −85) |
| P3 (기전 필수조건) | 유효 용량에서 Q(FOLD) 0-띠(±1.4칩) 점유율이 100%에서 유의미 하락 + 벳직면 콜 비율 상승 |
| P4 (위험 측정) | α_f=2.0에서 vsTAG 하락 가능(과콜 흥정) — ID 손실 허용선은 저자 결정 대기, 측정만 등록 |

**기각 기준**: 전 용량에서 vsMAN 양수 시드 ≤2/5(개선 없음) → FOLD-VIC(foldtime형) 기각 —
흥정 곡선·기전 지표만 기록하고 형태 변경(fixed형·상한 재설계)은 별도 게이트.
**판정 유보 조건**: P3 기전이 미발동(0-띠 그대로)인데 성적만 변하면 간접 채널 재발 —
CHECK판 소거전과 동일 절차로 원인 추적 후 판정.
