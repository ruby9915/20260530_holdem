# 이중 VIC(체크+폴드) 데이터 축적 로드맵 (2026-08-05)

> 원칙: 미지수 하나씩(저자 지시) · 매 단계 사전 등록 · 발사는 전부 저자 게이트.
> 목표 산출물: "같은 배분 안의 두 영-기여 행동을 구별 진단·순차 처방한" 완결 데이터 —
> 논문 통합(v4) 또는 후속 편의 재료. 총 코어 비용(0~2단계): 실기계 약 2~3일.

## 0단계 — 구현·무변화 검증 (반나절, 학습은 스모크만)

- `game.py`에 `--vic-fold {off, foldtime, fixed}` + `--vic-fold-amount` 구현.
  기본 off = **기존 결과 비트 동일** (체크포인트 검증 관례: 대표 설정 재실행 곡선 대조).
- 스모크 1런(2M): Q(FOLD)가 실제로 0 띠(±1.4칩)를 떠나는지 지문 확인
  (`fingerprint_qsign.py` 확장 — FOLD 축 추가).
- 산출: 구현 커밋 + 무변화 검증 기록.

## 0.5단계 — FOLD 임계 지도 선행 유도 (학습 0회 — "FOLD판 게이트 A" 준비)

CHECK에서 했던 절차의 대칭 적용: 기존 Q-테이블(k20-A12 chec_a30 5시드)의 **벳 직면 셀**에서
- 요구 지분 k_f = (최선 대안 CALL/RAISE 학습값) / (FOLD 참값 복원치) 를 역산,
- α_f_min 분포·커버리지 곡선을 만들고,
- **1단계 각 용량의 기대 성적을 런 전에 수치로 사전 등록**한다.
의의: 적중하면 임계 이론의 두 번째 out-of-sample 시험(게이트 A의 재판) — 논문 가치 배가.
빗나가도 CHECK판 게이트 B처럼 기각 기록 자체가 유효 범위 규정이 된다.
주의(정직): FOLD 참값 복원은 CHECK와 달리 "접은 뒤 결과 비관측" 문제로 근사가 개입 —
근사 가정을 등록문에 명시.

## 1단계 — FOLD 용량 사다리 (본 실험, 미지수 = 폴드 용량 하나)

- 플랫폼: **K20-A12 × TAG 학습** (게이트·교차표 맥락이 축적된 판).
- 베이스 고정: chec_a30 (검증된 CHECK 처방) — 변하는 것은 폴드 용량뿐.
- 런: foldtime α_f ∈ {0.05, 0.15, 0.30} × s1–5 = **15런** (7.5M eps, 13병렬 ~3h + 평가).
- 평가: 상대 6종 × 100k×5. 대조군 = 기존 chec_a30 5런(α_f=0, 재사용).
- **사전 등록(0.5단계 수치로)**: 주 판정 = vsMAN(현 −85, 2/5) 양수 전환 ∧ vsTAG 5/5 유지.
  기각 기준 = 전 용량에서 vsMAN 개선 없음 → FOLD-VIC 기각(흥정 곡선만 기록).
  기전 지표 = Q(FOLD) 0-띠 이탈률, CALL 양수 셀 수(현 26~32), 벳직면 콜 비율(행동 프로브).
- ID 손실 허용선: **저자 결정 필요** (제안: vsTAG 평균 −20% 이내).

## 2단계 — 전이 정밀화 + FOLD 상한 (1단계 결과 조건부)

- 전이가 걸리면 격자 세분(예: α_f 0.10, 0.20) ×5 = 10런.
- **FOLD 상한 탐침**: α_f ∈ {1.0, 2.0} ×5 = 10런 — CHECK와 달리 **상한이 실재할 첫 후보**
  (과용량 → 콜링스테이션 역병리). 상한이 나오면 그 자체가 CHECK와의 비대칭 발견,
  안 나오면 "양 행동 모두 관대"로 계열 성질 승격. 어느 쪽도 논문 문장이 됨.
- 핵심 칸 시드 확장(s6–10)으로 검정력 확보 — 통계검정 표를 이중 처방까지 연장.

## 3단계 — 이식성 검증 (교차 축)

- **legacy8 재현** (~1h): 최적 α_f 1점 ×5 — 무차원 임계가 FOLD 축에서도 플랫폼 이식되는지.
- **CFR-학습 판 1점** (조건부, 비용 큼 — 런당 11h): k20_a12_cfr 설정에 chec_a30+최적 α_f
  ×5 — **Maniac 역설(−1431)의 직접 해소 검증**. 성공 시 5단 한계(공격 상대 미회복)가 닫히는
  가장 극적인 실증. TAG 판 결과가 선 뒤에만 발사 권장.
- (선택) Slumbot 셀 1점, 7상대 스펙트럼 완성.

## 4단계 — 종합·논문 결정

- 3자 비교 완성: off vs chec 단독 vs chec+fold(최적) — "진단→처방→계열 완성"의 실증 아크.
- **집필 직전 표적 재정찰 1회** (복수 영-기여 행동 처방의 신작 유무 — 주 단위로 움직이는
  분야임을 감안한 마감 절차).
- 통합(v4) vs 분리(후속 편) 결정 — 데이터를 보고 저자가.
