# 주장 정리 최종본 (2026-08-14)

> 목적: 논문·심사 답변·서사 문서(저자해석 등)의 **단일 주장 원장**. 무엇을 어디까지
> 주장하고, 각 주장에서 선행연구가 차지하는 부분과 신규성의 경계, 데이터의 역할을
> 확정한다. 당연함 필터 감사(2026-08-14, 적발 5건) 반영판 — 감사 이력은 §7.
> 원칙: **자랑 금지 — 방어 가능한 최소 문언만.** 기본기(정직성·보수성·사전 등록 절차
> 자체)는 문장으로 내세우지 않고 그것이 생산한 결과물만 제시한다.

## 1. 주장 가능 목록 (방어 가능한 최소 문언)

각 문언은 "심사자 앞에서 물러설 필요 없는 가장 좁은 형태"다. **넓히면 안 되는 방향**을
병기한다 — 그 방향으로 한 발 나가는 순간부터 방어가 필요해진다.

1. **ZCA 진단**: 투자-비례 말단 credit 배분에서 비용 0 행동은 credit이 산술적으로 0이
   되고, 이 0은 방문할수록 재고정되는 영구 고정점으로서 argmax를 양방향으로 왜곡한다
   (음수 행동 흡수 + 양수 행동 은폐).
   근거: 28번 격리 + Q=0.000 지문(표준 MC ±100 대비) + 8M 무효(24번) + 4플랫폼 재현.
   ✗확대 금지: "credit 배분 일반의 병리", "실무에 만연".
2. **VIC 인과**: 본 환경에서 임계 초과 선택적 가상비용은 미학습 상대 일반화의
   필요조건이다 — 끄면 vs Random만 선택적으로 붕괴(−346~−3,339)하고 학습 분포 성적은
   보존된다. 근거: 2×3 ablation + 28b + 5시드. ✗확대 금지: "충분조건"(Maniac 반례),
   "일반 환경에서".
3. **선택성**: 표준 처방 3종(탐색 강화·낙관적 초기화·일률 벌점)은 병리를 해소하지
   못했다. 해소는 비용 0 행동에 대한 선택적 부여에서만 관측됐다. 근거: 31번 5시드
   전패(+일률 벌점의 예측 편차 기록). ✗확대 금지: "모든 기존 처방 실패"(3종 실측뿐).
   **커버리지의 정확한 경계(2026-08-14 검증)**: 실측 기각 = 세 반문 가족 대표 3종
   (①탐색: 교과서 / ②1회성 개입: Sutton&Barto 낙관 초기화 / ③일률 비용:
   action-penalty, Koenig&Simmons 1996) + 배분 포기 가족 대표(표준 MC, 29번) = 4종.
   이론 기각(실측 생략 명시) = **CHECK 선택적 낙관 초기화** — 영구성 실증(0의 재고정 +
   ②의 낙관값 세척 실측)이 1회성 개입의 실패를 함의; 요구 시 1일 예비 카드.
   비접촉 = 부트스트랩 가족(TD·double Q — 산술 교체는 연구 대상 소멸). 미실측 변형 =
   균등 배분(배분 포기 가족의 비대표). 논문 문장 후보: "실패하는 것은 1회성 개입,
   성공하는 것은 방문마다 걸리는 선택적 비용 — 선택성과 지속성이 모두 필요."
4. **저분산 보존의 가치**: 표준 MC로 회귀하면 병리는 없으나 동일 예산에서 양 지표 모두
   약하다(학습 상대에 1/7.5). 처방의 가치는 저분산 배분을 보존한 채 흡수만 해소하는 데
   있다. 근거: 29번 + PURE 5시드 3자 비교.
5. **임계 하한 (적중과 기각을 한 문장에)**: 칩 단위 고정 가상비용의 유효 임계를 학습
   없이 기존 Q-테이블에서 유도해 (5, 8]칩 구간으로 사전 등록했고 실험이 적중했다
   (급전이 포함). 같은 정적 유도가 팟-비례축에서는 약 5배 낙관으로 기각됐다(동적
   결합의 한계). 근거: 게이트 A(git 증빙) + 게이트 B. ✗확대 금지: "임계는 유도
   가능하다"(일반형 — 1승 1패라 즉시 반례).
6. **비대칭 용량-반응**: 하한은 수 %p 구간의 급전이, 상한은 α 53배·K 48배 범위에서
   미검출(시드 5·무검정 — 완만한 하락 배제 불가). 근거: 게이트 C·C-K + 극단 용량 절대
   앵커. ✗확대 금지: "상한 부재 확정".
7. **흡수-성능 분리** *(감사 적발 2 수정 반영)*: 흡수 해소가 성능 회복을 **보장하지
   않음**을 소거법으로 격리 실증했다(별도 채널 FOLD 영-고정; 역방향 — 흡수를 둔 채
   회복된 사례 — 는 미관측). 근거: 3중 소거 + 폴드 실험들의 교차 재현.
   ✗확대 금지: "필요조건"(그 방향의 소거 실험은 없음).
8. **강건성**: 위 결과는 표준 카드 추상화(percentile E[HS], Johanson et al. 2013)·확장
   행동축·상이한 학습 상대·독립 재구현 코드에서 재현된다. 근거: 33번 145런 + 사다리
   2~6단. ✗확대 금지: "모든 추상화에서"(Waugh 2009를 방어 인용으로 확보한 이유).

**+ 방법론 관찰 (주장 아님 — 보고)**: 단일 학습 시드가 OOD 결론의 부호를 뒤집은 사례를
실측·격리했다(28c; 절대 앵커에서 재발·재정정 — 3시드 규칙). 재현성 문헌([10][11][12])
원칙의 실측 예화로만 제시. 원칙 자체를 기여라 하지 않는다.

## 4. 신규성 문언 (확정)

> "투자-비례 말단 credit 배분이 비용 0 행동에 만드는 영-재고정 흡수를 명명·격리하고
> (ZCA), 기존 실패 모드 분류(본 조사 범위)에 없는 병리임을 보이며, 그 최소 처방이
> '선택적' 가상비용임을 경쟁 처방 전패와의 대조로 분리하고, 유효 용량의 하한을 학습
> 없이 유도해 사전 등록으로 적중시킨 것(칩축 한정)."

무너지는 확대 방향: "credit 병리 일반론" · "무행동 병리 첫 발견" · "새 처방
가상비용"(PBRS 틀 안 — 선택성만 신규) · "실무 시스템에서 확인".

## 5. 데이터 임팩트 순위 (역할 명기)

1. **28번 2×3 해리 표** — 병리 실재와 처방 인과를 동시에 지는 유일 데이터. 부호 해리는
   잡음으로 설명하기 **어려운** 형태이며, 5시드·격리 설계가 그 설명을 배제한다
   *(감사 적발 3 수정: "만들 수 없는" → "설명하기 어려운 + 설계가 배제")*.
2. **게이트 A 사전 적중** — 주장이 아니라 **인증**: 사후 설명 공격을 차단하고, 처방을
   "조율된 트릭"에서 "기전이 이해된 처방"으로 격상. 수혜자는 주장 1·2.
3. **31번 표준 처방 전패** — 신규성 문언의 "선택적"이라는 단어가 걸려 있는 대조군.
4. **PURE 3자 비교(29+30)** — 처방의 가치 제안 성립.
5. **사다리 재현(32·33)** — off 0/5·chec 5/5 패턴의 플랫폼 불변. C6·코드 의심 동시 방어.
6. **상한 미검출(게이트 C·C-K)** — 안전역 + 증폭형 기전 실증. (침묵 방침 결정에 따라
   폴드 양측 창과 대비쌍 편입 가능.)
7. **28c + 앵커 3시드 감사** — VI장 방법론 보고(원칙의 실측 예화 — 미덕 서술 금지).
8. **슬럼봇 앵커** — 신기루 검출·균형 상대 무해성·자릿수 한정. 비교 주장 사용 금지
   (3시드 규칙).

## 6. 서술 지침 (문언 수준)

- **자랑 금지**: 정직성·보수성·사전 등록 절차를 내세우는 문장 금지 — 산출물(적중 기록·
  기각 기록·규칙)만 제시.
- **장르**: 병리 진단 논문. 성능 수치는 개선 자랑이 아니라 병리 유무의 진단 지표
  (핵심은 크기가 아니라 부호 해리). "병리 논문의 요건" 류 자작 틀은 내부 작업용 —
  논문·답변에서는 계보 문헌 인용 경유로만 *(감사 적발 4)*.
- **TD·적용 범위** *(감사 적발 1 수정)*: "TD가 불가능한 도메인" 서술 금지 — RLB(Cai
  2017, bid=0 포함 DP·병리 없음)가 반례. 올바른 문언: **"말단 귀속(어트리뷰션) 회계를
  채택한 정식화에서 발생"** — 병리의 주소는 도메인이 아니라 배분 산술(본 논문 주장과
  정합). TD 경위 언급 시 "기본 TD(0), 본 환경·본 추상화 한정, 완화 기법(double Q 등)은
  범위 밖"으로 좁힘.
- **부재 주장**: 항상 조사 범위 한정 병기.
- **포커 hand = "핸드"**, 은어 금지, KCI 문체 — 용어집.md 우선.

## 7. 감사 이력 (2026-08-14 당연함 필터, 적발 5건 → 처리)

① "TD가 메뉴에 없는 환경" → 철회, "말단 귀속 회계 채택 정식화" 조건부로 교체(§6).
② 주장 7 "필요조건" 절반 → "보장하지 않음 실증 + 역방향 미관측"으로 완화(§1-7).
③ "부호 해리는 잡음으로 만들 수 없는 형태" → "설명하기 어려운 + 설계가 배제"(§5-1).
④ "병리 논문의 요건" 표 → 내부 작업 틀로 강등, 논문에서는 계보 인용 경유(§6).
⑤ 부재 주장 무한정 → 조사 범위 한정 병기(§3·§4).
