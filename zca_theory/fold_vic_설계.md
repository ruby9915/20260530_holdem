# FOLD-VIC 설계안 (2026-08-05) — 저자 게이트 대기

> 착수 조건(저자 지시 2026-08-04: "VIC 최적해 수식화 완료 후 순차, 미지수 하나씩") 충족.
> 본 문서는 설계·사전 등록 초안까지 — 구현·발사는 저자 승인 후.

## 1. 문제 (실측 근거)

FOLD는 CHECK와 같은 투자-0 행동으로, 비례배분에서 credit이 구조적으로 0 — 벳 직면 셀
전수에서 Q(FOLD)=0.00(±1.4칩 띠 100%, 전 조건·양 학습상대)이 실측됐다(실험일지 보강 25·26).
결과: 벳 직면 시 "0(FOLD) vs 학습 음수(CALL)"의 비교가 되어 과폴드로 붕괴 — CFR-학습의
Maniac 역설(−1431, 콜 양수 셀 0개), K20-A12 TAG-학습의 vsMAN 전패(보강 32)의 유력 원인.
FOLD는 판을 즉시 끝내고 결과를 관측하지 않으므로 자기교정도 차단된다(3중 차단).

## 2. 개입 설계

**원리**: 폴드에 가상 투자 v를 부여 → FOLD credit = v/(T+v) × payoff. 폴드한 판의 payoff는
−(자기 실투자)이므로 credit은 음수 — Q(FOLD)가 "이 맥락에서 접으면 평균 얼마를 포기하나"
방향으로 이동해 CALL·RAISE와 같은 장부에서 경쟁하게 된다 (CHECK-VIC와 동일한 "장부 참여"
원리의 대칭 적용).

**형태 후보**: ⓐ foldtime α_f × (폴드 시점 팟) — checktime과 대칭(권장: 팟-비례가 전
플랫폼 강건했던 실측 근거) ⓑ fixed K_f칩 (대조용 1점).

**구현**: `game.py` 폴드 분기에 가상 투자 부여(`--vic-fold {off,foldtime,fixed}` +
`--vic-fold-amount`). 기본 off = 기존 결과 비트 동일 보장(체크포인트·회귀 검증 관례 적용).

## 3. 예상과 위험 (사전 명기)

- **기대**: 벳 직면 셀에서 argmax가 0-기준점 대신 학습값끼리 비교 → 콜다운 회복 →
  vsMAN·vsRand 방어 개선. CALL 양수 셀 수(현 17~34)가 성능과 단조였던 실측이 근거.
- **위험 (CHECK-VIC와 상충 구조가 다름)**: 균형·타이트 상대(CFR·TAG)에는 폴드 위주가
  근사 정답 — 폴드 벌점은 **ID를 내주고 OOD를 사는 흥정**이 될 수 있고, 과용량이면
  콜링스테이션 역병리. **용량 창이 CHECK보다 좁을 것으로 추정**(상한이 실재할 첫 후보 —
  증폭형이라도 FOLD의 "참값" 자체가 맥락 의존 음수라 과대 증폭이 순위를 바꿀 수 있음).

## 4. 실험 설계 (단일변수, 사전 등록 초안)

- **베이스 고정**: chec_a30 (검증된 CHECK 처방) 위에 FOLD-VIC만 추가 — 미지수 하나.
- **플랫폼**: K20-A12 × TAG 학습 (Maniac 전패·교차표·게이트 A/B 맥락이 축적된 판).
- **런**: foldtime α_f ∈ {0.05, 0.15, 0.30} × s1–5 = 15런 (7.5M eps, ~2.5h/13병렬).
  대조 = 기존 chec_a30 5런(재사용, α_f=0).
- **판정 지표 (사전 고정할 것)**: 주 = **vsMAN**(현 −85±?, 2/5) 양수 전환 여부 +
  **vsTAG 5/5 유지**(ID 비용 측정) — "개선 없이 ID만 깎임"이면 기각. 보조 = vsRand(회복
  유지 확인)·vsSTA(참고)·vsLAG. 평가 6종 100k×5.
- **예측(등록 시 수치화)**: 하한 존재(α_f=0.05 무효 예상), α_f=0.15~0.30에서 vsMAN 개선.
  vsTAG 손실 허용선은 저자 결정 필요(예: 평균 −20% 이내).

## 5. 남은 결정 (저자)

① 발사 여부·시점 ② vsTAG 허용 손실선 ③ α_f 격자(제안: 0.05/0.15/0.30) ④ CFR-학습
판에도 병행할지(Maniac 역설 직접 검증 — 런당 11h라 비용 큼, TAG 판 결과 후 판단 권장).
